Расчёт опорного случая статьи занимает доли секунды.

Стохастическое вертикальное перемешивание: тысячи траекторий уравнения Ито с оседанием и турбулентной диффузией. Параметры диска и частицы (кроме размера) берутся из вкладки «Расчёт траектории».

dz = [ vs + ∂D/∂z + D ∂ln ρg/∂z ] dt + √(2D) dW
vs = −Ω St(z) z,   D = αt Ω H2 / (1 + St2)
Дюбрюль: Hd = H √(α / (α + St))

Сравнение толщины пылевого слоя Hd: стохастическая модель, точное стационарное решение и формула Дюбрюля.

20 000 траекторий считаются за доли секунды.

Модель

Одна сферическая пылинка радиуса a и плотности ρd движется в газовом диске вокруг звезды типа T Тельца. Силы: гравитация звезды (тонкий диск), трение о газ, центробежная и кориолисова, при включённом заряде — сила Лоренца. Основа — В. А. Кобозева (СПбГУ, 2025), уравнения (11).

dr/dt = vr
dvr/dt = j2/r3 − M/r2 − (vr − ur)/τsцентробежная, гравитация, трение
dj/dt = −(r/τs)(j/r − uφ)j = r vφ: газ тормозит пылинку по азимуту
dz/dt = vz,   dvz/dt = −M z/r3 − vz/τsвертикальная гравитация и трение
da/dt = Yd ρ |v − u| / (4 ρd)рост при сборе мелкой пыли

Безразмерные единицы: r0 = 1 а.е., v0 = (GM☉/а.е.)1/2 ≈ 29.8 км/с, t0 = r0/v0 ≈ 0.159 года.

Трение о газ

τEp = ρd a / (ρ vth)Эпштейн, a < 3λ/2
τSt = (2/9) ρd a2 / ηСтокс, a ≥ 3λ/2
St = τs ΩKчисло Стокса

vth = (8kT/πμmH)1/2, η = vthλρ/3, λ = μmH/(ρσ). При a = 3λ/2 выражения совпадают, τs непрерывна. Быстрее всего дрейфуют тела с St ≈ 1.

Дрейф и диск

uφ = vK (1 − βK)1/2
vr = (ur/St − βK vK) / (St + 1/St)стационарный дрейф
βK = [ −(r/ρ) ∂p/∂r + r BzBr/(4πΣ) ] / vK2самосогласованный, ур. (16)

Газ вращается чуть медленнее кеплеровского, пыль чувствует встречный ветер и дрейфует внутрь. В максимуме давления βK = 0 — там ловушка. Аналитический диск Дудорова–Хайбрахманова: T ∝ r−9/8, ρ0 ∝ r−21/16, H ∝ r15/16, ρ(r,z) = ρ0 e−z²/2H². Край мёртвой зоны: ρ → ρ · [1 + A(1 + tanh((r − rb)/w))/2].

Заряд и поле

F = (Ze/c)(v − u) × Bсила Лоренца

Остаточное поле Bz = B0(r/а.е.)−p, Br = q Bz. OML-заряд — оценка сверху (не учитывает эффект Хавнеса).

Численные методы

DOPRI5

Явный Рунге–Кутта 5(4), PI-регулятор шага, плотный вывод для событий, суммирование Кэхэна. Быстр для крупных тел без жёсткости.

BDF 1–5

Неявный многошаговый метод переменного порядка (форма Шампайна–Райхельт). Ньютон с LU или Ньютон–Крылов (GMRES). Для мелкой пыли, где τs ≪ периода.

auto

Старт явным методом и переход на BDF при распознанной жёсткости: h|λ| у границы устойчивости и оценка спектрального радиуса.

Якобиан

Аналитический, включая производные диска и силу Лоренца; проверен разностями. Главное ускорение: все расчёты статьи — 0.1 с.

События

Корень по плотному выводу методом Брента: достижение rin, вход в полосу осаждения, остановка в ловушке.

СДУ

Эйлер–Маруяма, Мильштейн и линейно-неявный Эйлер (снос жёсткий высоко над экватором); xoshiro256++ с отдельным потоком на траекторию.
