# Testing

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build
ctest --test-dir build                     # 65 tests: Catch2 cases, allocation audit, CLI
./build/tests/cpp/dpd_tests "[paper]"      # only the paper regression
pip install ".[test]" && pytest tests/python   # against the *installed* package
```

`tests/python/conftest.py` refuses to run against the source tree.

## Reference data and provenance

`tests/cpp/reference_data.hpp` is generated by `tests/reference/generate_references.py`
(SciPy, never by this code):

- Robertson: SciPy Radau, rtol 1e-13, analytic Jacobian.
- Van der Pol mu = 1000: SciPy LSODA (ODEPACK), rtol 1e-12.
- Dust model: `tests/reference/dust_model_scipy.py`, an independent NumPy re-implementation
  of Eqs. (11) integrated with LSODA at rtol 1e-10. It shares the physical interpretation
  (A1-A4 in physics_model.md) but no code; agreement verifies the implementation, not the
  interpretation.

Paper values (`test_paper.cpp`) are copied from the tables with 2-3 significant figures.
Tolerances: 3-5 % for times (rounding + two calibrated parameters), 2 % for the
reference case, 10 % for values read from figure descriptions. Cases that do not agree
are documented in `reference_case.md` and are not asserted.

## Tolerance policy

Tests never assert global errors at the local tolerance. Bounds are either explicit
multiples justified in the test (e.g. `2 * n_steps * rtol` for accumulating relative
errors, `100 * rtol` for BDF) or convergence checks (error must drop by >= 20x for
100x tighter rtol). No bound was loosened without stating why in the test.

## Sanitizers and portable build

```bash
cmake -S . -B build-asan -DCMAKE_BUILD_TYPE=Debug -DDPD_SANITIZE=address,undefined
cmake -S . -B build-scalar -DDPD_ENABLE_SIMD=OFF
```

Both run the full suite in CI. UBSan found undefined behaviour in toml++'s formatter
(float with negative exponent), which is why `to_toml` has its own writer.
ThreadSanitizer is not part of CI yet (ensembles are covered by the bitwise
serial/parallel equality test).
